# Documentación del Sistema de Internacionalización (i18n)

Esta guía documenta la arquitectura, el funcionamiento y el mantenimiento del sistema de traducción bilingüe (Español / Inglés) implementado en el frontend de CELIG.

---

## 1. Visión General

El sistema permite ofrecer versiones completas en **Español (idioma por defecto)** e **Inglés** de todo el contenido estático del sitio público de CELIG sin alterar las rutas ni la administración privada (`/admin/*`).

### Características Principales:
- **Control por URL**: Mediante parámetros query `?lang=en` o `?lang=es`.
- **Persistencia Inteligente**: Cookie `celig_lang` con duración de 1 año para recordar la preferencia del usuario en visitas posteriores.
- **Navegación Fluida**: Los enlaces internos del sitio preservan automáticamente el idioma seleccionado (`getLocalizedPath`).
- **Botón Conmutador (`LanguageToggle`)**: Ubicado en la barra superior junto al botón de menú (`top-2 right-[128px] md:right-[134px]`), mostrando `ES | EN` con indicador visual de estado activo.
- **Alcance**: Páginas públicas (Inicio, Servicios, Testimonios, UI de Contenido, Políticas, WhatsApp, Formularios de contacto y Metadatos SEO). El módulo administrativo (`/admin/*`) permanece en español.

## 3. Funcionamiento y Resolución del Idioma

La resolución del idioma activo se realiza en `src/i18n/utils.ts` mediante la función `getLangFromUrl(url, cookieHeader)` siguiendo esta prioridad:

1. **Parámetro Query (`?lang=en` o `?lang=es`)**: Máxima prioridad. Si la URL contiene `?lang=en`, se mostrará en inglés inmediatamente.
2. **Cookie `celig_lang`**: Si el usuario entra a una URL limpia (ej. `/servicios`), se revisa la cookie para restaurar su preferencia previa.
3. **Idioma por Defecto (`es`)**: Si no hay parámetro ni cookie previa, se renderiza en español.

## 4. Uso en Componentes Astro y React

### En Componentes Astro (`.astro`)
```astro
---
import { getLangFromUrl, useTranslations, getLocalizedPath } from "@/i18n";

// 1. Obtener idioma actual
const lang = Astro.props.lang || getLangFromUrl(Astro.url, Astro.request.headers.get("cookie"));

// 2. Instanciar función de traducción
const t = useTranslations(lang);
---

<!-- 3. Usar textos del diccionario -->
<h1>{t("home.landing.title1")}</h1>
<p>{t("home.landing.title2")}</p>

<!-- 4. Generar enlaces internos que preservan el idioma -->
<a href={getLocalizedPath("/servicios", lang)}>
  {t("nav.services")}
</a>
```

### En Componentes React (`.jsx` / `.tsx`)
```jsx
import { translations } from "@/i18n/ui";

export function MiComponente({ lang = "es" }) {
  const t = translations[lang] || translations.es;

  return (
    <div>
      <button>{t.contactForm.submit}</button>
    </div>
  );
}
```

## 5. Cómo Agregar Nuevas Traducciones

1. **Abrir `src/i18n/locales/es.json`**:
   Añade la nueva clave en la sección correspondiente:
   ```json
   {
     "home": {
       "nuevaSeccion": {
         "titulo": "Nuevo Título",
         "descripcion": "Descripción en español"
       }
     }
   }
   ```

2. **Abrir `src/i18n/locales/en.json`**:
   Añade la misma clave con su respectiva traducción al inglés:
   ```json
   {
     "home": {
       "nuevaSeccion": {
         "titulo": "New Title",
         "descripcion": "Description in English"
       }
     }
   }
   ```

3. **Consumir la clave en el componente**:
   ```astro
   <h2>{t("home.nuevaSeccion.titulo")}</h2>
   <p>{t("home.nuevaSeccion.descripcion")}</p>
   ```

## 6. Servicios y Contenido Dinámico Estático

Los servicios con contenido extenso (`src/data/servicios.ts`) cuentan con versiones dedicadas:
- `serviciosEs`: Artículos en español.
- `serviciosEn`: Artículos completos traducidos al inglés.
- `getServicios(lang)` y `getServicioBySlug(slug, lang)`: Retornan el contenido en el idioma solicitado.

## 7. Sistema de Filtros / Etiquetas Bilingües (`ContenidoEtiquetas.astro`)

Para permitir que el usuario visualice las etiquetas en su idioma seleccionado (ej. *"Family Law"* en inglés o *"Derecho Familia"* en español) y al mismo tiempo el backend API reciba el identificador exacto de la base de datos:

1. **Visualización y Mapeo**: `ContenidoEtiquetas.astro` renderiza los botones con la etiqueta traducida en su texto visible y coloca el tag de la base de datos en el atributo HTML `data-api-tag` (ej. `data-api-tag="Derecho Familia"`).
2. **Consumo en React (`ContenidoBlogsReact.jsx`)**: Al hacer clic en la etiqueta, el componente lee `e.target.getAttribute("data-api-tag")`, enviando al backend el valor correcto sin importar el idioma visible.
